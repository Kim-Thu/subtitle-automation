User Guide & Feature Reference

Getting Started

Auto Subtitle Pro generates subtitles, translations and optional dubbing for supported video files.

  1. Upload a supported video or place it inside inputs.
  2. Refresh the dashboard if needed.
  3. Select Whisper model, translation engine, target language and subtitle style.
  4. Click Process for one video or Process All for batch execution.

Supported containers: .mp4, .avi, .mov, .mkv, .webm.

Translation Engines

  • Google Translate: General-purpose translation with automatic source-language detection.
  • ✨ Gemini AI: Context-aware subtitle translation. Requires a Gemini API key.
  • Ollama Local: Local translation through an Ollama model running on the default local service.

Dubbing & Audio Merge

  • Dubbing enabled: Generates a dub track with Microsoft Edge TTS.
  • Audio Merge ON: Mixes the dub track with the original audio at reduced original volume.
  • Audio Merge OFF: Replaces the original audio track with the generated dub track.
  • Final output: When dubbing succeeds, the dubbed video becomes the final downloadable artifact.

Current Feature Status

  • Smart Subtitling: Whisper speech-to-text is the primary transcription flow.
  • Manual Inputs: Existing SRT or manual script content can be used during processing.
  • OCR: Present in the repository but currently experimental/legacy and not a supported primary web workflow.
  • Processing Queue: Backend processing uses a bounded worker pool; excess jobs remain queued.
