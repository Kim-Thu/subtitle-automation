User Guide & Feature Reference

Getting Started

Welcome to Auto Subtitle Pro. This tool automates the process of generating subtitles and dubbing for your videos.

  1. Place your video files in the inputs folder.
  2. Refresh the dashboard list.
  3. Select translation engine and target language.
  4. Click Process on individual videos or Process All for batch execution.

Translation Engines

  • Google Translate: Free, reliable, good for general purpose. No API key required.
  • ✨ Gemini AI: High quality, context-aware translations. Requires a Google AI Studio API Key.
  • Ollama Local: Private, runs locally. Requires Ollama installed and running (default port 11434).

Features

  • Smart Subtitling: Uses OpenAI Whisper for accurate speech-to-text.
  • Auto Dubbing: Generates AI voiceovers using Microsoft Edge TTS (multilingual support).
  • Manual Scripting: You can supply your own script to correct transcription errors before translation.
  • Audio Merge: Automatically mixes the new dub track with the original background audio (ducking).
