Troubleshooting & Help

Common Issues

1. Videos not showing up?

Make sure the file is inside inputs or uploaded through the dashboard, then refresh the list. Supported containers are .mp4, .avi, .mov, .mkv and .webm.

2. Ollama translation failed?

Make sure Ollama is installed and running. Run ollama serve and verify the selected model is available with ollama list.

3. Error during "Burning Subtitles" or audio processing?

FFmpeg is required. Ensure FFmpeg is installed and available in your system PATH, or available through the application's bin directory.

4. Dubbing finished but audio is not what you expected?

Check the Audio Merge setting. When enabled, the dub is mixed with the original audio. When disabled, the dub replaces the original audio track.

5. Upload rejected before processing?

The app rejects files over the configured upload limit, corrupt media, files without a video stream, and unsupported codecs before queueing expensive processing. The default upload limit is 2048 MB.

6. Where can I find error details?

Check the terminal window running python app.py. The current dashboard does not expose a dedicated Logs button.

Bug Reports & Feature Requests

When reporting a problem, include the processing stage, selected engine/model, target language, relevant terminal error, and the smallest reproducible example you can share.

Use the repository's GitHub Issues for bugs, feature requests and implementation discussions.
