# Auto Subtitle Pro - UI References

These mockups define the approved redesign direction for Auto Subtitle Pro.

## Screens
- workspace.jpg - overall video-processing workspace
- home.jpg - Home / project overview
- subtitle-editor.jpg - subtitle editing workspace
- dubbing-studio.jpg - per-segment dubbing and sync workspace
- export-publish.jpg - export and publishing workspace
- settings.jpg - settings and diagnostics workspace

## Design direction
- Dark navy / charcoal media-production UI
- Blue accent system
- Persistent left navigation
- Large primary working canvas
- Contextual right-side inspector
- Segment-level subtitle and dubbing workflows
- Clear processing, validation, sync and export states

These images are product references, not exact pixel specifications. Implementation should preserve the information architecture and interaction priorities while adapting to the actual application capabilities.
